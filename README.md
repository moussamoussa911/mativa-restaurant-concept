# Mativa Restaurant Concept

Modernes, dreisprachiges Website-Konzept für das Restaurant Steakhaus Mativa in Gronau-Epe.

## Lokal starten

```bash
npm start
```

Danach: `http://localhost:4402`

## Inhalte

- Mehrseitiger Aufbau
- Deutsch, Niederländisch und Englisch
- Interaktive Speisekarte mit Tisch-Zusammenstellung
- Reservierungsassistent mit Öffnungslogik
- Responsive Navigation und rechtliche Seiten

Dieses Projekt ist ein unverbindliches Designkonzept. Reservierungsanfragen werden in der Demo nicht an das Restaurant übertragen.
